# Требования к сайту образовательной организации

Основано на следующих нормативных документах:

1. **Федеральный закон 29.12.2012 № 273-ФЗ**, статья 29 (информационная открытость).
2. **Постановление Правительства РФ от 10.07.2013 № 582** (правила размещения информации на сайте).
3. **Приказ Минобрнауки России от 14.08.2020 № 458** (требования к структуре официального сайта образовательной организации).

## Реализация в проекте

| Требование | Где реализовано |
|------------|-----------------|
| Основные сведения, контакты, лицензия, учредитель | Страница `/info`, раздел «Основные сведения» (данные `data/school-info.json`). |
| Структура и органы управления | `/info#structure`. |
| Документы (устав, лицензия, аккредитация) | `/info#documents` (ссылки на файлы). |
| Образовательные программы, стандарты, численность обучающихся | `/info#programs` (таблица программ и описание ФГОС). |
| Стипендии и платные услуги | `/info#programs` блок «Платные услуги» и «Стипендии». |
| Материально-техническое обеспечение и доступная среда | `/info#inclusion`. |
| Педагогический состав | `/info#personnel`. |
| Финансово-хозяйственная деятельность | `/info#finance`. |
| Вакантные места для приёма (вакансии) | `/info#vacancies`. |
| Международное сотрудничество | `/info#international`. |
| Контактная информация и горячая линия | `/info#contacts` и футер сайта. |

## Поддержка и обновление
- Данные хранятся в `data/school-info.json`. Для обновления сведений достаточно изменить значения в JSON.
- Дата актуальности (`lastUpdated`) выводится в шапке страницы.
- Для добавления новых разделов расширьте JSON и шаблон `views/pages/info.handlebars`.
